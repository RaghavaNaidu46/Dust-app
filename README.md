# Dust — support site

Public pages for [Dust](https://github.com/RaghavaNaidu46/Dust), a macOS menubar app that
shows what is actually inside "System Data" and frees it safely.

Served by GitHub Pages at <https://raghavanaidu46.github.io/Dust-app/>.

| Page | Used for |
|---|---|
| `index.html` | Marketing URL |
| `support.html` | Support URL |
| `privacy.html` | Privacy Policy URL |

Static HTML and one stylesheet — no build step, no dependencies, no trackers.
